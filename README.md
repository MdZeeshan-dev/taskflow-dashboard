# TaskFlow Dashboard

TaskFlow Dashboard is a modern task management application built using HTML, CSS, and JavaScript. It helps users organize, prioritize, and track tasks through an interactive dashboard interface.

## Live Demo

https://taskflow-dashboard-wheat.vercel.app/

## Features

* Create and manage tasks
* Search tasks instantly
* Set task categories
* Assign priority levels
* Add due dates
* Track Total, Completed, and Pending tasks
* Filter tasks by status
* Dark mode support
* Clear all tasks functionality
* Responsive dashboard design

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## Installation

```bash
git clone https://github.com/MdZeeshan-dev/taskflow-dashboard.git
cd taskflow-dashboard
```

Open `index.html` in your browser.
